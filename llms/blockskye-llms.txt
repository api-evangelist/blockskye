# Blockskye

> Enterprise travel management and payments platform for large corporate travel
> programs. Blockskye combines a consumer-grade online booking tool sourced through
> direct supplier and NDC connectivity, BMAX direct settlement (ERP-to-supplier,
> removing corporate cards and expense reports for booked travel), B360 personal
> co-brand card loyalty capture under policy, and real-time cross-channel reporting,
> with transactions recorded to a tamper-resistant distributed ledger. Delivered
> end-to-end in partnership with KAYAK for Business.

## API surface — read this before assuming an integration path

Blockskye publishes **no public developer portal, no API reference, and no
machine-readable API contract**. There is no OpenAPI, Swagger, GraphQL schema,
AsyncAPI document, MCP server, or A2A agent card discoverable from any Blockskye
host. Integration is an enterprise sales and onboarding motion, not a self-serve
developer signup.

A live production API host does exist and answers anonymously:

- https://api.blockskye.com — Fastify service behind AWS API Gateway.
  `GET /health` returns 200. All other probed routes return a structured JSON 404.
  Responses carry `X-RateLimit-Limit: 100`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`.
  No specification is served at `/openapi.json`, `/swagger.json`, `/documentation/json`,
  `/docs`, `/redoc`, `/graphql`, or any `/.well-known/*` path.

Customer-facing surfaces, both gated:

- https://horizon.blockskye.com/login — the booking, servicing and settlement application.
- https://support.blockskye.com/support/home — knowledge base; redirects to Freshworks OAuth.

## Products

- Online Booking Tool — consumer-grade booking with policy enforced at book time, sourced directly from suppliers.
- BMAX Direct Settlement — settlement orchestration connecting a customer ERP directly to suppliers.
- B360 — lets travelers earn loyalty on personal co-brand cards for business trips while the company keeps policy visibility and control.
- Blockskye Reporting — real-time analytics and program intelligence across every booking channel.
